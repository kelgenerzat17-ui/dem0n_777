1. Базовые теги — артефакты из Дневника №3

HTML состоит из тегов — подсказок для браузера. Большинство тегов парные: открывающий <p> и закрывающий </p> со слешем.

  • <h1>...</h1> — главный заголовок эпичной страницы.
  • <p>...</p> — обычный абзац текста.
  • <a href="...">...</a> — гиперссылка (как те карточки персонажей выше!).

2. Каркас страницы — твой корабль перед отплытием

Прежде чем покорять сеть, собери правильный каркас документа. Без него браузер не поймет, где начало и конец страницы. 

<!DOCTYPE html>
<html lang="ru">
<head>
    <title>Мой сайт</title>
</head>
<body>
    <h1>Привет, мир!</h1>
</body>
</html>
