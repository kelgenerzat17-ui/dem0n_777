ЧИБИ ЗОРО: ССЫЛКИ И СПИСКИ

Чтобы не заблудиться между страницами сайта, нужны точные гиперссылки и структурированные списки.

Как создаются гиперссылки

За переходы отвечает тег <a> с обязательным атрибутом href, в котором указывается адрес назначения:

• Внутренняя ссылка на другую страницу твоего сайта: <a href="quiz.html">Пройти тест</a>.
• Внешняя ссылка на другой сайт в новой вкладке: <a href="https://..." target="_blank">Документация</a>.

Списки в HTML

Для перечислений используют два вида списков, а каждый пункт внутри оборачивают в <li>:

• <ul> — маркированный список (с точками).
• <ol> — нумерованный список (1, 2, 3...).
